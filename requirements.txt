# ── Chatbot embeddings ────────────────────────────────────────────────
# torch is a transitive dependency of sentence-transformers. Left
# undeclared it resolves from PyPI to the CUDA build, which drags in
# ~2.5GB of nvidia wheels (cublas, cudnn, nccl, cusparselt, cusolver,
# cufft, curand, …) — none of which can be used in a CPU-only container.
# That alone accounted for roughly 7.6GB of the built image.
#
# Declaring it here with the +cpu local version forces the CPU wheel:
# that build exists ONLY on the PyTorch index, so the resolver cannot
# silently fall back to the CUDA one from PyPI.
#
# The version is pinned deliberately. `torch` unpinned with an
# --extra-index-url is not reliable — pip can still pick the PyPI build
# depending on version ordering. When upgrading, check what the CPU
# index actually offers:
#   https://download.pytorch.org/whl/cpu/torch/
--extra-index-url https://download.pytorch.org/whl/cpu
torch==2.13.0+cpu
